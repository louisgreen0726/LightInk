# 需求：轻墨 LightInk — 轻量护眼 Markdown 桌面编辑器

日期：2026-08-08

## 一屏摘要

- 目标：「轻墨 LightInk」——一款对标 Typora 的单栏所见即所得 Markdown 桌面编辑器（R1）
- 使用者：个人用户，核心场景是阅读/整理 AI 生成的文档与个人笔记（R10）
- 范围：所见即所得编辑、本地文件与多标签、图片管理、代码高亮、导出、主题、大纲、公式、流程图（R1–R9）
- 关键规则：颜值高、操作简单、护眼默认、低资源占用，四者是最高优先级设计约束（R6、R11、R12）
- 成功标准：Windows/macOS/Linux 三平台可安装且核心功能一致；冷启动 ≤ 3 秒、常规编辑内存 ≤ 150MB（R12、R13）
- 不做事项：云同步/协作、移动端、插件系统、Web 版本（R14、R15）

## 完整需求

### R1 单栏所见即所得编辑

采用 Typora 式单栏即时渲染：用户输入 Markdown 语法后即时渲染为排版结果，光标进入时显示源码、离开时恢复渲染，不提供分屏预览模式。覆盖常用语法：标题（1–6 级）、有序/无序/任务列表、引用、行内代码与代码块、表格、链接、图片、粗体/斜体/删除线、分割线。

验收：

- 输入各级标题、列表、引用、表格、链接等语法后，离开该行即渲染为对应排版，无分屏或预览窗格
- 光标进入已渲染元素时可看到并编辑其 Markdown 源码
- 从空白文档到完成一篇含全部常用语法的文档，全程无需切换任何模式

### R2 本地文件管理与多标签页

支持本地 .md 文件的新建、打开、保存、另存为；支持多标签页同时编辑多个文件；关闭未保存文件时提示；意外退出后可恢复未保存内容。

验收：

- 新建→编辑→保存→关闭→重新打开，内容往返无损（含中文与特殊字符）
- 可同时打开多个文件并在标签页间切换，各文件编辑状态互不影响
- 关闭含未保存修改的标签页时出现保存提示；强制结束进程后重启可恢复未保存内容

### R3 图片管理

支持从剪贴板粘贴图片、从文件管理器拖入图片；图片保存到本地（文档相对目录或统一资源目录），文档中以相对路径引用。

验收：

- 截图后直接粘贴，图片落盘并在文档中正确显示
- 拖入本地图片文件后正确显示，移动文档及其图片目录后引用不丢失

### R4 代码块语法高亮

代码块按指定语言进行语法高亮，至少覆盖常见语言（JavaScript/TypeScript、Python、Java、Go、Rust、C/C++、HTML/CSS、SQL、Shell、JSON、YAML）。

验收：

- 标注语言的代码块渲染出对应语言的高亮配色
- 未标注语言的代码块以纯文本样式正常显示

### R5 导出 HTML / PDF

可将当前文档导出为 HTML 和 PDF 文件，导出内容包含渲染后的排版、图片、表格、代码高亮。

验收：

- 导出的 HTML 在浏览器打开后与编辑器内渲染结果一致
- 导出的 PDF 可正常打开，中文无乱码、图片完整、排版无错位

### R6 主题与护眼

默认主题为柔和护眼配色（低对比暖色背景、非纯白），提供深色模式；支持自定义主题。主题为全局即时生效。

验收：

- 首次启动默认即为护眼配色，非刺眼的纯白背景
- 一键切换深色/浅色，切换即时生效且各语法元素配色协调
- 自定义主题文件替换后渲染样式随之改变

### R7 大纲侧栏

根据文档标题层级生成大纲/目录侧栏，可点击跳转，随编辑实时更新；可折叠隐藏。

验收：

- 编辑含多级标题的文档时，大纲实时反映当前标题结构
- 点击大纲条目后文档滚动定位到对应标题

### R8 数学公式

支持行内与块级 LaTeX 数学公式（$...$ 与 $$...$$）的即时渲染。

验收：

- 输入常见公式（如二次方程求根公式、积分式）后正确渲染为排版公式
- 公式源码语法错误时原样显示源码，不导致文档其他部分渲染异常

### R9 流程图

支持 mermaid 代码块即时渲染为流程图/时序图等图形。

验收：

- 合法 mermaid 代码块渲染为对应图形
- 语法错误时显示错误提示或源码，不影响文档其余内容

### R10 AI 文档场景支持

针对 AI 生成内容的典型形态（标题层级、代码块、表格、列表、公式混合的长文档）保证粘贴即正确渲染：从 AI 聊天工具复制的 Markdown 源文本粘贴后结构完整还原。

验收：

- 将一段 AI 生成的含代码块、表格、多级标题的 Markdown 源文本粘贴入编辑器，全部元素一次正确渲染，无格式丢失
- 处理万字级 AI 生成文档的打开与滚动，无明显卡顿

### R11 高颜值与简单易用

界面现代简洁、排版精致；核心操作（新建、打开、保存、切换主题、导出）入口直观可达，无需阅读说明书即可完成。

验收：

- 首次使用的用户不借助文档即可在 1 分钟内完成新建→编辑→保存
- 界面无冗余工具栏按钮堆叠，常用操作不超过两次点击/一个快捷键

### R12 低资源占用与性能

采用轻量技术架构，控制安装体积、启动时间与运行内存。目标：冷启动 ≤ 3 秒；常规编辑场景内存占用 ≤ 150MB；万字级大文档场景 ≤ 300MB；安装包体积显著小于同类 Electron 编辑器。

验收：

- 在中等配置机器上冷启动到可编辑 ≤ 3 秒
- 打开并编辑一篇常规长度文档时，进程内存占用 ≤ 150MB
- 打开万字级文档时内存占用 ≤ 300MB
- 连续编辑 1 小时无明显内存持续增长导致的卡顿

### R13 三平台桌面交付

一期同时交付 Windows、macOS、Linux 三个平台的可安装版本，核心功能（R1–R6）在三平台表现一致。

验收：

- 三平台各自完成安装→启动→新建→编辑→保存→导出全流程
- 同一文档在三平台打开渲染结果一致

## 不做事项

### R14 云同步与多人协作

不提供账号体系、云端存储、多设备同步或多人实时协作；数据完全本地存储。与当前范围的边界：本地文件读写（R2）属于交付范围，任何网络存储与同步均不交付。

验收：

- 应用无需注册/登录即可完成全部功能
- 功能列表与设置界面中不存在云同步、协作相关入口

### R15 移动端、插件系统与 Web 版本

不交付 iOS/Android 移动端、第三方插件扩展机制、浏览器 Web 版本。与当前范围的边界：自定义主题（R6）属于内置能力，不属于插件系统。

验收：

- 交付物仅为 Windows/macOS/Linux 桌面安装包
- 应用不存在插件安装/加载入口
