# 需求：PDF 原生阅读与标注组件重做

日期：2026-08-14

## 一屏摘要

- 目标：PDF 不再是纯位图——文字可选中、复制、搜索，并可在 PDF 上划选文字做高亮；标注三个组件（划选工具栏、笔记编辑器、标注侧栏）全套重做（R1、R2）
- 使用者：LightInk 桌面阅读器用户，阅读 PDF/flow/txt 文档并做标注（R1）
- 范围：PDF 文本层 + PDF 内搜索；统一划选工具栏；多行笔记编辑弹层；侧栏筛选/分组/编辑；PDF 文字高亮持久化（R1、R2、R3、R4）
- 关键规则：已保存的 v2 标注数据必须兼容加载、不丢历史标注（R5）
- 成功标准：PDF 文字可选中复制、搜索可定位命中处；三格式划选可经工具栏加高亮/笔记；旧标注加载后原样可见可跳转（R1–R5）
- 不做事项：PDF 重排版（reflow）、高亮多色、标注导出、CBZ 文字类标注（R6）

## 完整需求

### R1 PDF 文本层与文字交互

在现有 pdfjs canvas 页面渲染之上叠加文本层：PDF 文字可被鼠标选中、可复制到剪贴板，选区视觉与页面内容对齐不漂移。渲染保持 PDF 原始版式、字体与背景（继续以 canvas 保真栅格化为底）。文本层随缩放/翻页/懒渲染生命周期正确重排与回收，不引入可感知的滚动卡顿或内存增长。

验收：

- 打开任意文本型 PDF，鼠标可划选文字，Ctrl+C 复制出的文字与页面显示一致（不含多余换行/空格干扰到无法阅读的程度）。
- 缩放（+/-/0）后文字仍可选中，选区与页面内容对齐。
- 快速滚动大 PDF（数百页）时无明显卡顿；关闭文档后再打开，内存不持续增长。
- 扫描件（无内嵌文字的 PDF）不显示可选中文字，不报错。

### R2 PDF 内搜索

提供 PDF 内文字搜索：输入关键词后列出/跳转到命中位置。搜索基于文本层提取的文字，命中后跳转到对应页并定位到命中处（可视高亮提示）。无命中时给出明确提示。

验收：

- 打开含目标词的 PDF，搜索该词可跳转到命中页并定位到命中文字处。
- 多个命中可逐个跳转（上一个/下一个）。
- 无命中时显示"无结果"类提示，不崩溃。
- 搜索框关闭后阅读状态不受影响。

### R3 统一划选工具栏

选中正文文字后在选区附近弹出行内工具栏，提供"高亮"与"笔记"入口，替换现有"划选即直接高亮"（flow/txt）与"PDF 无法划选"的行为。工具栏对 flow、txt、PDF 三种格式统一生效；点击工具栏外或取消选区后工具栏消失。已加高亮的文字再次选中时可移除高亮。

验收：

- flow/txt 文档中划选文字出现工具栏；点"高亮"生成高亮，不再不经确认直接高亮。
- PDF 中划选文字出现同一工具栏；点"高亮"在 PDF 页面文字层上生成持久高亮。
- 点"笔记"弹出笔记编辑器（R4），保存后该文字带高亮并关联备注。
- 选中已高亮文字时工具栏提供"取消高亮"入口，点击后移除该高亮。
- 点击工具栏外部、按 Esc 或清空选区，工具栏消失且不产生标注。

### R4 笔记编辑器与标注侧栏重做

笔记编辑器：以多行输入弹层替换 `window.prompt`，支持新建备注与编辑已有备注（修改后保存生效）。

标注侧栏重做：在现有跳转/删除能力之上，增加按类型（高亮/书签/笔记）筛选或分组、显示每条标注的定位信息（页码或章节）、编辑备注入口。侧栏数据与正文标注实时同步（新增/删除/编辑后两侧一致）。

验收：

- 新建笔记时弹出多行输入弹层，可输入多行文本，取消则不创建。
- 从侧栏打开已有笔记可编辑，保存后侧栏与正文（如有关联高亮）更新。
- 侧栏可按高亮/书签/笔记筛选，每条显示页码或章节定位。
- 在正文新增/删除标注后，侧栏列表即时反映；反向操作同样同步。

### R5 标注数据向后兼容

已有按内容哈希持久化的 v2 标注 JSON 必须继续加载：历史高亮/书签/笔记原样显示在侧栏且可跳转。PDF 新增文字级高亮需要文字级定位；历史页码级 PDF 书签/笔记沿用页码定位并正常跳转。不迁移、不丢弃、不静默改写历史数据文件中的既有字段语义。

验收：

- 使用包含 v2 标注的旧数据文件打开对应文档，全部历史标注可见、可跳转、可删除。
- 旧 PDF 页码级书签/笔记在新版本中跳转行为不变。
- 新旧标注可在同一文档共存并一起持久化，重开后均恢复。

## 不做事项

### R6 明确排除项

不做 PDF 重排版（reflow）阅读模式——PDF 只走 canvas 保真 + 文本层方案；不做高亮多色/自定义样式（维持现有单一样式）；不做标注导出（Markdown/PDF 等）；不做 CBZ 的文字类标注（CBZ 维持页级书签）。

验收：

- 交付中不出现 PDF 文本抽取重排版界面或入口。
- 高亮只有一种样式，无颜色选择 UI。
- 无任何标注导出功能入口。
- CBZ 格式不出现划选工具栏。

## 来源
